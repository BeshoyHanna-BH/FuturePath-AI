# FuturePath AI

FuturePath AI is a one-file Python desktop application that helps students discover suitable career paths based on their skills, interests, and academic background.

## Project Type

- Single-file Python app
- Desktop GUI using `tkinter`
- No extra project modules required
- Designed to run by double-clicking the Python file

## Main File

- `FuturePathAI.pyw`

## What The App Does

- Lets the user choose an academic background
- Lets the user rate their skills and interests from 0 to 10
- Recommends the top 3 career paths
- Explains why each career matches
- Shows strengths, improvement areas, and a starter roadmap

## Supported Career Paths

- Software Engineering
- Data Science
- UI/UX Design
- Digital Marketing
- Biotechnology
- Business Analytics

## How To Run

### Option 1: Double-click

On Windows, double-click:

- `FuturePathAI.pyw`

This opens the app directly without a terminal window.

### Option 2: Run from terminal

```powershell
python FuturePathAI.pyw
```

Or, if you are using the local virtual environment:

```powershell
.\.venv\Scripts\python.exe FuturePathAI.pyw
```

## Requirements

- Python 3 installed
- `tkinter` available in your Python installation

No external libraries are required for this final one-file version.
